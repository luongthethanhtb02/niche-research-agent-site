Project policy

Privacy Policy

This policy describes how Niche Research Agent handles data for its internal analytics and research purpose.

Public YouTube Data

The tool uses only public data made available through the official YouTube Data API. This may include public video information, public channel metadata, publicly available subscriber counts, and public playlist or upload information.

No Private User Data

No private YouTube user data is collected. The tool does not request OAuth authorization, does not access private account information, and does not access non-public videos, playlists, subscriptions, or user activity.

How Data Is Used

Public YouTube Data API data is used only for internal analytics and research. The tool uses this information to build auditable research samples and, where permitted under applicable YouTube API Services policies, calculate factual indicators about public content niches. It does not use the data for account management, video uploads, or automated actions on a user's behalf.

Data Retention, Refresh, and Deletion

Data retention, refresh, and deletion practices follow applicable YouTube API Services policies. Stored YouTube API data is refreshed or deleted as required by applicable YouTube API Services policies. Any longer-term storage of statistical or derived data is used only where permitted under applicable YouTube API Services policies and any required approvals.

No Tracking Technologies

This website does not use tracking scripts, analytics tools, cookies, third-party JavaScript, or data-collection forms.
