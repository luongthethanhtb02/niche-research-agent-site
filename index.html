Niche Research Agent

An internal analytics and research tool designed to evaluate YouTube content niches using publicly available YouTube Data API data.

Public data only Official YouTube Data API only No account access

Purpose

The tool supports structured market research for YouTube content planning. It collects a controlled sample of public video and channel information, checks the quality of that sample, and is designed to calculate factual indicators that help researchers understand activity within a defined content niche, subject to applicable YouTube API Services policies.

Data Used

The tool uses public information returned by the official YouTube Data API, including:

  • Video titles and descriptions
  • Publication dates and view counts
  • Public channel metadata
  • Subscriber counts when available
  • Public playlists and upload information

Analytics

The tool is designed to calculate research metrics from public API data, subject to applicable YouTube API Services policies and any required permissions, including:

  • Observed niche views
  • Channel concentration
  • Video performance distribution
  • Breakout and outlier signals
  • New and small channel performance indicators
  • Sampling quality indicators

Observed metrics describe the collected sample. They are not estimates of total YouTube market coverage.

No Private Data

The tool does not collect private YouTube data, request OAuth user access, or access private account information. Research is limited to public data available through the official YouTube Data API.

No Upload or Account Management

The tool has no video upload functionality and does not manage channels, videos, comments, subscriptions, playlists, or user accounts.

No Scraping

The project does not scrape YouTube pages, download competitor videos, or use browser automation to collect YouTube data. Data acquisition uses the official YouTube Data API only.

Data Handling

Collected public data is used only for internal analytics and research. Access is limited to the project purpose, and retention, refresh, and deletion practices follow applicable YouTube API Services policies.

Read the Privacy Policy

Use Case

The tool helps an internal research team compare content niches, review public market activity, evaluate whether a collected sample is sufficiently broad and reliable, and identify areas that may warrant further human research. It does not publish content or make changes to YouTube accounts.
