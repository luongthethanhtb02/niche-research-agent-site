Project terms

Terms of Service

These terms describe the current scope and use of the Niche Research Agent project.

Project Scope

Niche Research Agent is an independent, internal analytics and research tool for evaluating public activity within defined YouTube content niches. It is not currently offered as a public software-as-a-service product or paid service.

Data Source and Permitted Use

The tool is designed to use public data made available through the official YouTube Data API. Use of API data, retention, refresh, deletion, and derived analytics is subject to applicable YouTube API Services policies and any required permissions or approvals.

No Private Account Access

The tool does not request OAuth authorization, collect private YouTube user data, or access private account information. It has no video upload functionality and does not manage YouTube accounts, channels, videos, comments, subscriptions, or playlists.

No Scraping or Video Downloading

The project does not scrape YouTube pages, use browser automation to collect YouTube data, or download competitor videos. Its YouTube data-acquisition boundary is the official YouTube Data API.

Internal Research Use

Public API data and permitted derived analytics are used only for the project's internal analytics and research purpose. The tool is not used to publish content or take automated actions on a YouTube user's behalf.

No Affiliation or Approval Claim

Niche Research Agent is an independent project. It does not claim approval, audit, certification, endorsement, partnership, or sponsorship by Google or YouTube.
